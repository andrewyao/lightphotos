# Keyboard shortcuts

Press `?` (`Shift`+`/`) in the app for the built-in overlay.

| Key | Action |
| --- | --- |
| `G` | Grid view |
| `E` / `Enter` | Loupe (open selected) |
| `Esc` | Step back one level; from the grid root, prompts to quit |
| Arrows | Move grid selection / step the loupe (`Shift` extends the selection) |
| `Tab` / `Shift`+`Tab` | Cycle keyboard focus between regions (folders, grid, toolbar, develop, filmstrip) |
| `PageUp` / `PageDown` | Step to the prev/next image while in the detail or develop panel |
| `1`–`5` | Rate current image; `0` clears |
| `Shift`+`1`–`5` | Set a "≥ N stars" filter; `Shift`+`0` clears |
| `B` | Toggle best-of-burst badges (Grid) |
| `D` | Toggle content-duplicate badges (Grid) |
| `Y` | Toggle before/after compare (Loupe) |
| `+` / `-` | Adjust thumbnail size (Grid) |
| Scroll | Zoom (Loupe) |
| `Space`+drag | Pan (Loupe) |
| `Cmd`+`[` / `Cmd`+`]` | Rotate (Loupe) |
| `Alt`+`0` | Reset to 100% |
| `C` | Crop mode (Loupe): drag edges, `Shift` keeps ratio, `C`/`Enter` commits, `Esc` cancels |
| `Cmd`+`Z` | Delete the selected touch-up (while touch-up editing is active) |
| `Cmd`+`Shift`+`C` / `Cmd`+`Shift`+`Y` | Copy develop settings / apply them to the selection |
| `Cmd`+`A` | Select every visible cell (Grid) |
| `Delete` | Move the selection to the Trash (after a confirm) |
| `X` | Export selected image as `.jpg` in the same folder (edits baked in, never overwrites) |
| `?` | Toggle the shortcut-help overlay |
